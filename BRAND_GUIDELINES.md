# Vizcatch Analytics - Brand Guidelines

## 1. Identidad Central
"Vizcatch Analytics" combina una estética tecnológica y minimalista. El núcleo visual es la "vizcacha", estructurada con arte lineal moderno, transmitiendo agilidad, visión profunda (catch) y precisión analítica.

## 2. Paleta de Colores
La identidad se basa en un tema oscuro (*Dark Mode*) por defecto, con acentos en tonos morados neón para resaltar elementos clave.

| Color | Hex | Uso Principal |
| :--- | :--- | :--- |
| **Dark Void** | `#010102` | Fondo principal de la aplicación, banners y reportes. |
| **Catch Purple** | `#7368CF` | Color central del isotipo y de la palabra "analytics". Botones primarios. |
| **Neon Accent** | `#8278D3` | Brillos, *hover states* de botones, y gradientes. |
| **Deep Shadow** | `#3A3562` | Bordes, separadores sutiles o fondos de tarjetas. |
| **Tech White** | `#F1F1F1` | Texto principal ("vizcatch"), iconos secundarios y cuerpo de texto. |

## 3. Tipografía
Para mantener la coherencia con el logo, se recomiendan fuentes geométricas y legibles, optimizadas para interfaces de datos:

*   **Tipografía Principal (Títulos y Headers):** `Inter` o `Plus Jakarta Sans`. Estas fuentes tienen un excelente balance de pesos y un *x-height* alto que favorece la lectura en dashboards.
*   **Tipografía Secundaria (Cuerpo y Tablas):** `Roboto` o `Geist`. Ideales para lectura de alta densidad de datos.
*   **Tipografía Monospace (Código/Métricas):** `JetBrains Mono` o `Fira Code`. Para mostrar valores crudos, JSONs o bloques de código.

## 4. Ecosistema de Logotipos
Se han generado y extraído las siguientes variaciones en la carpeta `/public`:

1.  **Logotipo Principal Horizontal (`logo.jpeg` / transparente):** El estándar para la cabecera de la web (navbars).
2.  **Isotipo Independiente (`isotipo.png`):** Solo la vizcacha. Uso obligatorio para avatares (GitHub, LinkedIn) y el Favicon.
3.  **Versión Apilada / Vertical (`logo_vertical.png`):** Isotipo centrado sobre el wordmark. Ideal para formatos cuadrados, portadas de repositorios y pantallas de carga.
4.  **Versión Light Mode (`logo_light_bg.png`):** Variante diseñada específicamente para fondos blancos/claros, donde el texto blanco cambia a carbón (`#1A1A1A`) manteniendo el morado de la marca intacto.

## 5. Reglas de Uso
*   **Contraste:** Nunca colocar el logo principal (texto blanco) sobre fondos claros sin usar la versión alternativa (`logo_light_bg`).
*   **Proporción:** El isotipo debe mantener sus proporciones originales; no comprimir ni estirar.
*   **Clear Space (Área de Seguridad):** Dejar un margen equivalente al ancho de la "v" de vizcatch alrededor del logo donde no interfieran otros elementos.
